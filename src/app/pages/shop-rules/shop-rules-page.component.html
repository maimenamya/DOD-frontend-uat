กะร้าน / ตัดกะ

เวลาเข้า–ออกงานของพนักงานตั้งที่หน้า ตำแหน่ง (แต่ละตำแหน่งเข้างานคนละเวลาได้) — เวลา on floor ของ PR แท็กตั้งในส่วนด้านล่าง — ส่วนนี้ใช้กับยอด «คืนนี้» และการตัดกะอัตโนมัติของร้าน

เวลาเริ่มช่วงยอดคืนนี้บนแดชบอร์ด — ไม่ใช่เวลาเข้างานพนักงาน

หลังเวลานี้ของวันถัดจากกะ ระบบปิดกะและหักลืมแสกนออก — ว่างไว้ = ปิดฟีเจอร์

PR แท็ก → สาย on floor

ใช้กับเด็กนั่งดริ้งที่ติดแท็ก PR — ถ้า on floor หลังเวลานี้ ระบบคิดค่าปรับมาสาย (อัตราต่อนาทีตั้งด้านล่างในส่วนหักขาด/สาย) — ว่าง = ใช้เวลาเข้างานของตำแหน่งนั้น

PR freelance สาย → หักดื่มเข้าร้านเพิ่ม

แยกจากเวลา on floor ของแท็กด้านบน — ถ้าเข้างานหลังเวลาที่ตั้ง ระบบหักดื่มเข้าร้านเพิ่มต่อดื่มตอนจ่ายค่าดื่ม freelance (เช่น หักปกติ 60 + เพิ่ม 20 = ร้านหัก 80) — ว่างเวลา = ปิดฟีเจอร์
